Process the inbox of this vault.

## Before you start

1. Read CLAUDE.md first and follow it throughout.
2. List every file currently in 00_inbox. Process all of them.
3. Plan the changes for all captures before making any. If the plan would modify more than 20 files (created, updated or moved), show the plan and ask for approval before proceeding.

## For each capture

1. Read the capture fully.
2. Identify the distinct meaningful ideas in it.
3. Split multiple meaningful ideas into separate notes when appropriate.
4. Search the existing vault before creating a new note.
5. Prefer updating an existing note when appropriate.
6. Apply the routing rules in CLAUDE.md. If classification is uncertain, keep the capture in 00_inbox and ask.
7. Preserve my original thinking and wording. Clean grammar and structure only.
8. Use lowercase_with_underscores filenames.
9. Start substantive notes with a one-line summary.
10. Preserve source information.
11. Add meaningful [[wikilinks]] to genuinely related notes.
12. Add a Links section to substantive notes.
13. Distinguish FACT, SOURCE CLAIM, MANAGEMENT GUIDANCE, MY VIEW, INFERENCE and QUESTION where relevant.
14. Never turn an inference into a fact.
15. Never delete information.
16. Move the processed raw capture to 40_archive/inbox_processed/.

| Capture | Notes created | Notes updated | Links added |
|---|---|---|---|

List any captures left in 00_inbox, and why, below the table.
