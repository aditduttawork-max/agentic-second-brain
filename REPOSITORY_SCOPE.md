# Repository Scope

This repository contains the version-controlled Second Brain instructions, command definitions, Instinct protocol, rules, templates, and documentation.

## Included

- `CLAUDE.md`
- `.claude/commands/`
- `_system/instinct/`
- `_system/templates/`
- `docs/`
- `instinct/`
- `.gitignore`
- `LICENSE`
- `README.md`
- `REPOSITORY_SCOPE.md`

## Excluded

- Obsidian workspace state
- private vault notes
- queue runtime files
- generated outputs
- backups
- temporary test artifacts
- provider usage exports
- credentials, API keys, sessions, and secrets

## Principle

The GitHub repository is the reusable system definition. Runtime state and private knowledge remain outside version control.
